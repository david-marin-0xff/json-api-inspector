# JSON API Inspector

A lightweight developer tool for inspecting and validating JSON API responses.

## Features

- JSON formatting
- Validation
- Search/filtering
- Pretty printing
- Copy to clipboard
- Dark mode UI

## Technologies

- HTML
- CSS
- JavaScript

## Future Improvements

- Tree view rendering
- JSON schema validation
- API fetching
- Diff comparison
- Security scanning

## Example Use Cases

- API debugging
- Learning JSON
- Security testing
- Developer tooling
- API response inspection
